BUILT FOR YOUR LOCAL WORKFLOW ComfyUI · Audio-first

A little studio, built around your ears.

  1. Open a video or audio file and drag over the waveform to select an interval.
  2. Write a prompt, optionally choose a voice reference, and generate variations with the built-in H3 preset, or import recordings.
  3. Listen, select a take, adjust Take start if needed, and export a WAV with the take mixed into the selected interval.

For lip-sync, choose the speaker, track the face, draw an oval around the mouth and review it across the passage before rendering. See README for limits.
